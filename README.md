# XV Floral Editorial

Plantilla de invitación digital de XV años con estética floral, marfil, rosa empolvado y champagne.

## Ejecutar

```bash
npm install
npm run dev
```

## Personalizar

Edita `src/config.js` para cambiar nombre, fecha, hora, lugar, WhatsApp, padres, padrinos, portada y galería.

## Publicar

```bash
npm run build
```

Después puedes conectar el proyecto con Netlify.
